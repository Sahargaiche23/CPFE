3.2 Avantages GitHub Actions

  • Integre a GitHub — pas de serveur separe a gerer
  • YAML simple — fichiers .github/workflows/*.yml
  • Marketplace riche — actions pretes a l'emploi
  • Runners gratuits — 2000 minutes/mois (plan gratuit)
  • Self-hosted runners — possibilite d'utiliser ses propres serveurs

6. Monitoring et Logging

6.1 Installation via Helm

# Installer Prometheus + Grafana
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm install prometheus prometheus-community/kube-prometheus-stack \
  --namespace monitoring --create-namespace

# Installer Loki pour les logs
helm repo add grafana https://grafana.github.io/helm-charts
helm install loki grafana/loki-stack --namespace monitoring
