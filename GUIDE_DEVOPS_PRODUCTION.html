3. Outils d'Intégration Continue (CI/CD)

3.1 Comparatif des outils

Outil Points forts Points faibles Idéal pour
GitHub Actions Recommandé Intégré à GitHub, YAML simple, marketplace riche, runners gratuits Minutes limitées (plan gratuit) Projets GitHub, équipes modernes
Jenkins Très extensible, plugins nombreux, gratuit Configuration complexe, UI vieillissante Entreprises avec besoins spécifiques
Azure DevOps Intégration Azure/MS parfaite Vendor lock-in Environnements Microsoft

3.2 Pourquoi GitHub Actions ?

  • Intégré à GitHub — pas de serveur séparé à gérer
  • YAML simple — fichiers .github/workflows/*.yml
  • Marketplace riche — actions prêtes à l'emploi
  • Runners gratuits — 2000 minutes/mois (plan gratuit)
  • Self-hosted runners — possibilité d'utiliser ses propres serveurs

6.1 Installation via Helm

# Installer Prometheus + Grafana
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm install prometheus prometheus-community/kube-prometheus-stack \
  --namespace monitoring --create-namespace

# Installer Loki pour les logs
helm repo add grafana https://grafana.github.io/helm-charts
helm install loki grafana/loki-stack --namespace monitoring
